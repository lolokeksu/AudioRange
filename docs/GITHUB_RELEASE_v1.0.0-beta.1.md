# AudioRange v1.0.0-beta.1

Initial public beta of AudioRange.

## Verified target

- Realme GT Neo 5 SE / RMX3700
- Android 13 / Realme UI 4.0
- APatch
- `STREAM_MUSIC` maximum confirmed at 30

## Important

Other firmware, Android 14–16, KernelSU and Magisk are experimental until device reports confirm the effective `AudioService` range. The module changes logical volume steps, not physical amplifier power.

Verify the downloaded files against `SHA256SUMS`.
